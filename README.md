# iPhone-Aufräumer

Eine iPhone-App, die große und überflüssige Fotos und Videos findet, sie in einen Ordner
der Dateien-App kopiert und erst nach geprüfter Kopie und ausdrücklicher Bestätigung löscht.

Status: in Entwicklung. Entwurf: `docs/superpowers/specs/`. Plan: `docs/superpowers/plans/`.

Gebaut wird auf GitHub (macOS-Server), installiert wird mit Sideloadly. Siehe `ANLEITUNG.md`.
